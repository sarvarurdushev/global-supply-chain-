# Data Sources (supply-chain layer)

The inherited God's Eye View sources are documented in the repository-root
[`DATA_SOURCES.md`](../DATA_SOURCES.md), preserved verbatim from upstream. That file remains
authoritative for aircraft, vessels, satellites, earthquakes, CCTV, transit, traffic,
terrain, geocoding and the bundled infrastructure datasets.

This file covers the sources **added by the supply-chain layer**. Licence obligations for
both sets are consolidated in [`DATA_LICENSE_MATRIX.md`](DATA_LICENSE_MATRIX.md); reachability
and fitness-for-purpose, with measured probe results, are in
[`DATA_AVAILABILITY_MATRIX.md`](DATA_AVAILABILITY_MATRIX.md).

## UN Comtrade

| | |
| --- | --- |
| **Used for** | Bilateral trade by HS commodity: value (USD) and net weight (kg) |
| **Endpoint** | `https://comtradeapi.un.org/public/v1/preview/C/{A\|M}/HS` |
| **API key** | **Not required** for the public preview endpoint |
| **Licence** | UN Comtrade terms of use |
| **Attribution** | `Source: UN Comtrade (comtradeplus.un.org)` — **required** |
| **Redistribution** | Cache with a TTL; **do not republish bulk extracts** |
| **Client** | `src/supplychain/sources/comtrade.js` |

**Measured constraints** (2026-09-16 — these shape the client, see
`DATA_AVAILABILITY_MATRIX.md` §1.1):

- **Exactly one period per call.** Multiple periods return HTTP 400. A ten-year series is ten
  sequential calls.
- **HTTP 429 under back-to-back calls.** `getTimeSeries()` pauses between calls; a server-side
  proxy must also cache and throttle.
- **Description fields return NULL** (`reporterISO`, `partnerISO`, `cmdDesc`, `flowDesc`), so
  codes are resolved against locally bundled tables.
- **`qty` is frequently 0 with `isQtyEstimated: true`.** `netWgt` is the usable volume field.
- Rows carry `isReported`, `isAggregate` and `legacyEstimationFlag`, which reach the
  provenance panel rather than being dropped.

## World Bank Indicators API v2

| | |
| --- | --- |
| **Used for** | GDP, population, trade shares, manufacturing, high-tech exports, energy imports, container traffic |
| **Endpoint** | `https://api.worldbank.org/v2/country/{iso3}/indicator/{code}` |
| **API key** | Not required |
| **Licence** | **CC BY 4.0** |
| **Attribution** | `Source: World Bank — data.worldbank.org (CC BY 4.0)` — **required** |
| **Redistribution** | Permitted with attribution |
| **Client** | `src/supplychain/sources/worldbank.js` |

Response shape is a two-element array (`[pagination, data]`). Observations with a null value
are **dropped and counted**, never coerced to zero — a missing GDP figure is not a GDP of
zero.

Indicator codes carry their unit in `INDICATORS`, because mixing `NY.GDP.MKTP.CD` (current
US$) with `NY.GDP.MKTP.KD` (constant 2015 US$) produces a nonsense series.

## NGA World Port Index

| | |
| --- | --- |
| **Used for** | Port identity, location, harbour type and size, channel and anchorage depth, UN/LOCODE |
| **Endpoint** | `https://msi.nga.mil/api/publications/world-port-index?output=json` |
| **API key** | Not required |
| **Licence** | **US Government public domain** (17 U.S.C. §105) |
| **Attribution** | `Source: National Geospatial-Intelligence Agency, World Port Index` (courtesy) |
| **Payload** | 6.3 MB, 2,951 ports, 112 fields each — fetch server-side, ship a slim derived subset |

**Measured field reliability** — this dataset is authoritative but unevenly populated:

| Reliable | Coverage |
| --- | --- |
| `xcoord` / `ycoord` | **100%** |
| `harborType` | 99% |
| `harborSize` (4-level ordinal, **not** throughput) | 99% |
| `anDepth` / `chDepth` | 89% / 87% |
| `unloCode` | 86% |

| **Unusable** | Coverage |
| --- | --- |
| `loContainer`, `loLiquidBulk`, `loSolidBulk`, `loOilTerm`, `loRoro` | **~1%** |
| `maxVesselDraft` | 3% |
| `cranesContainer` | 4 ports |

**Consequence:** WPI gives excellent port identity, location and physical scale. It does
**not** give port commodity specialization, which is recorded as DATA-LIMITED rather than
inferred from a 1%-populated field.

## GDACS — Global Disaster Alert and Coordination System

| | |
| --- | --- |
| **Used for** | The `supply-events` layer and the EVENTS AFFECTING SUPPLY CHAINS panel |
| **Endpoint** | `https://www.gdacs.org/gdacsapi/api/events/geteventlist/EVENTS4APP` |
| **Key** | **None.** Verified 2026-09-16: HTTP 200, 135 KB, 100 events |
| **Licence** | GDACS terms of use — free public access, attribution expected |
| **Attribution** | "Source: GDACS — Global Disaster Alert and Coordination System (European Commission / UN)" |
| **Data class** | 🟢 **LIVE**. The only supply-chain layer in this project that legitimately carries a LIVE badge |
| **Proxied** | Yes — `/api/supplychain/events`, 5-minute TTL. gdacs.org sends no CORS headers, so a direct browser fetch is blocked |

**What it covers**: earthquakes, tropical cyclones, floods, volcanoes, droughts, wildfires.

**What it does not cover**: strikes, port closures, sanctions, trade restrictions, conflict.
Those are the human-caused disruptions §15 of the brief also asks for, and GDACS does not
carry them. The layer states this rather than letting an empty map imply that nothing
happened. See `docs/DATA_AVAILABILITY_MATRIX.md` §3 item 12.

**Alert level is not a hazard measurement.** Green/Orange/Red is GDACS's own modelled estimate
of likely humanitarian impact. A Green earthquake can still be a large earthquake in an
unpopulated area, and nothing in this project treats the alert level as a supply-chain impact
score.

**Proximity is not impact.** `linkEventsToNodes()` reports the ports and chokepoints within
500 km of an event and attaches a caveat saying so verbatim. A cyclone 200 km from a port may
close it for a week or miss it entirely, and this data cannot tell the difference.

## Sources deliberately not used

| Source | Reason |
| --- | --- |
| WTO Timeseries API | Returned **401** — requires a subscription key this project does not hold |
| UNCTADstat | Probed endpoint returned 400; API shape undocumented for our use |
| ACLED | Requires a registered account; academic licence with redistribution limits. GDACS is used for natural hazards instead, and covers nothing human-caused |
| EM-DAT | Requires an account; academic licence |
| Lloyd's List / Drewry / Alphaliner | Commercial, paywalled — port throughput |
| SEMI / TechInsights | Commercial, paywalled — fab capacity |
| Panjiva / ImportGenius | Commercial — bills of lading, the only route to per-shipment cargo |

Each is recorded as BLOCKED in `DATA_AVAILABILITY_MATRIX.md` §3, and the dependent feature is
degraded in the UI rather than faked.

## Standing obligations

1. Every new source registers in `src/data/dataCredits.js`, which routes per-layer credits
   into the expandable "Data attribution" lightbox. **A source that renders without a credit
   is a licence violation, not a cosmetic bug.**
2. UN Comtrade extracts are cached with a TTL, never republished in bulk.
3. Rate limits are licence terms, not performance advice.
4. ODbL share-alike propagates to derived databases, including graph edges whose geometry
   derives from OSM/Overpass.
